六大 Agent 功能使用教程

面向企业体验与外部评审：按界面逐项说明能做什么、怎么演示、哪些按钮不要点，以及每个 Agent 的工程亮点。

统一桌面商境PicAgent ComicFlowChunk Lab智能检索CPPT

体验原则：只浏览、配置、预览和查看任务队列。所有「生成 / 一键精修 / 开始解析 / 向量化 / 提交训练 / 启动 GPU / 推理」等可能触发真实模型、存储或云端计费的按钮，现场只讲解不执行。

0. 统一桌面与登录

  1. 打开统一入口，输入账号与密码。
  2. 桌面展示 6 个应用：训推平台、ComicFlow、PicAgent、Chunk Lab、智能检索、商境。
  3. 点击图标后网关才为该应用授权；新标签页打开应用前必须先点击图标。
  4. 体验结束后点击右上角用户菜单，选择「锁定并退出登录」。

亮点：Nginx auth_request 统一网关、逐应用授权、HttpOnly Session、飞书 OAuth2 + PKCE。

1. 商境 · 电商内容智能创作

以商品长期聊天为入口、项目无限画布为核心的图文/视频内容生产系统。

  1. 工作台查看跨项目运行中、待处理任务。
  2. 商品页用聊天、表单或素材建档，查看事实、建议与历史。
  3. 项目画布查看商品输入、图片输入、提示词、生图、改图、合成、视频、输出八类节点。
  4. 观察文本/图片/视频端口类型校验、节点版本切换与任务队列状态。
  5. 系统 → 模型中心查看 4 渠道 12 模型；密钥只显示末四位。
  6. 素材与回收站查看结果素材、版本来源与恢复边界。

亮点：AI 只建议；用户预览范围再开始；同编号与参数幂等；提交/轮询失败分级；来源固定到具体成功版本。

2. PicAgent · 商品套图工作台

把商品实拍图、平台规则和勾选事实组织成可审阅的套图生产链路。

  1. 创建方案并上传 1–6 张商品原图。
  2. 白底精修查看候选与历史 attempt，不覆盖旧版本。
  3. 爆品图反推只提炼构图与光影，不覆盖产品外观事实。
  4. 简报选择 Amazon 等平台，查看首图白底、附图、文字与人物限制。
  5. 勾选允许使用的 Chunk；未勾选时显式标「缺失事实」。
  6. 生成结构建议 → 人工确认 → 按类别生成提示词 → 物化为画布任务卡。

亮点：两阶段 LLM 编排 + 人工确认闸门；RAG 事实约束；提示词/来源快照；attempt 版本血缘。

3. ComicFlow · 故事到漫剧视频

把中文故事拆成剧本、分镜、角色卡、画面、字幕和导出任务的异步生产线。

  1. 新建项目并输入中文故事，查看预计 Credit 与成本门禁。
  2. 依次查看故事审阅、剧本、分镜、角色、画面、字幕/时间轴、导出。
  3. 打开阶段产物，查看版本号、依赖状态与任务详情。
  4. 上游修改后观察下游依赖失效标记，不自动重跑付费任务。
  5. 导出页说明 FFmpeg 服务端拼接与结果归集。

亮点：Celery 异步长任务、阶段产物版本化、局部依赖失效、成本门禁、导出产物可追溯。

4. Chunk Lab · 电商文档审阅台

把 PDF/图片/Office 文档解析成有来源、可人工校正的 Chunk，再进入 Context 审核。

  1. 左栏添加文档，选择 VLM/Pipeline、语言、OCR、表格、公式。
  2. 中间文档舞台查看原页、来源框、页码、缩放与来源锁定。
  3. 使用选择、新建、批选、合并、拆分、排除、删除、撤销等标注工具。
  4. 右侧选择切分策略，调整参数并生成预览，查看指标分布。
  5. 对 Chunk 做校正与 Context 审核，理解 generating / awaiting_review / confirmed / failed / stale 生命周期。

亮点：结构感知/语义切分、父子块、来源定位、人工审阅、Context 生命周期、pgvector 写入边界。

5. Agentic Retrieval · 智能检索工作台

比较不同检索策略，检查真正送给回答模型的证据并验证引用。

  1. 输入查询，例如 USB-C 快充。
  2. 依次切换 Dense / BM25 / Hybrid / Hybrid + Rerank，对比召回、分数与延迟。
  3. 展开 Context Pack 查看真正送给答案模型的证据。
  4. 核对 Citation 是否落在证据范围内；失败、降级、拒答显式展示。
  5. 对比页一次运行四种配置；评测页查看 Recall@K、Precision@K、MRR、nDCG@K 与可选 Ragas。

亮点：只读 adapter、服务端权威证据、显式失败态、引用校验、OpenAPI 生成 TS SDK。

6. CPPT · 训推平台

把数据集校验、微调、Adapter 管理、推理服务和云 GPU 调度做成可运营流水线。

  1. 系统概览查看平台状态、任务队列与资源概况。
  2. 数据集查看校验报告、样本、版本与修复入口。
  3. 训练任务查看 LoRA / QLoRA 参数、YAML 配置即代码、队列、日志与 Loss 曲线；不提交训练。
  4. 模型管理查看 base / Best / Final Adapter 与归档恢复。
  5. 推理服务查看列表、健康状态、单 GPU 租约与 SSH 失败恢复边界；云 GPU 只讲解不启动实例。

亮点：配置即代码、eval_loss 选 Best、单 GPU 租约、云端恢复、资源生命周期清理。

推荐演示顺序

统一桌面登录 → 商境工作台 → 商境项目画布 → 商境模型中心 → Chunk Lab → 智能检索 → PicAgent → ComicFlow → CPPT → 退出登录。

收尾话术：这条链路覆盖「文档切成可信 Chunk → 可追溯检索 → 平台规则约束下的套图/视频生成 → 任务队列与版本血缘 → 底层模型训推」；贯穿三个工程原则：AI 输出先约束再进入状态、生成类任务异步幂等可追溯、供应商通过适配层隔离。
